# Running it on a laptop

Replaces the deployment guide deleted on 2026-08-24. Four machines, no install,
no server.

## What you receive

**One file.** `DnyaniMitr_v3.3.0.html`, about 460 kB.

That is the entire application — code, styles, and the Seva Sankalp mark are all
inside it. There is nothing to keep alongside it and nothing to unzip.

## Putting it on a machine

1. Copy the file anywhere the person will find it again — Desktop is fine.
2. Double-click it. It opens in the browser.
3. **Bookmark it**, or make a Desktop shortcut. That is the whole install.

No internet is needed, then or ever.

## Which browser

**Chrome or Edge.** Both are current on every Windows machine and handle
Devanagari and the date fields correctly.

Firefox works. Internet Explorer does not, and neither does the old "Microsoft
Edge Legacy" — if the icon is a blue **e** rather than a blue-green swirl, it is
the wrong one.

## The one thing to explain

**Each laptop keeps its own separate register.** Opening the same file on two
machines does not give you the same data — the data lives in the browser, not in
the file.

To bring two machines together, use सेटिंग → बॅकअप आणि शेअर on one and paste into
the other. Exactly as the phones do.

## What does not work on a laptop, by design

- **Notifications** and **SMS** — Android only. The buttons are inert.
- **Opening a backup file from WhatsApp** — Android only.

WhatsApp Web works for sending greetings, if they are signed in.

## Moving to a new machine

The register does not travel with the file, so:

1. On the old machine: सेटिंग → बॅकअप आणि शेअर → copy the text.
2. Send it to yourself however is easiest.
3. On the new machine: open the file, then paste it into बॅकअप आणि शेअर.

## If the page is blank

Almost always the wrong browser. Try Chrome.

If it is blank in Chrome too, press **F12**, click **Console**, and send us the
red text. It names the file and the line, and it is worth more than a screenshot.
